# Benchmarks

## Evaluation discipline

Future results must name the dataset/version, code revision, environment, sample size, metric
definition, baseline, failure exclusions, and reproducible command. Targets are labeled `TARGET` and
must never be presented as observations. Retrieval, intent, constraint safety, payment invariants,
latency, and recovery will be measured separately so aggregate scores do not hide unsafe failures.
